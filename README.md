### 🚀 About Me

I'm a Master's student in Medical Informatics at FHNW with a strong interest in software engineering, data science, and medical imaging. I'm a passionate fullstack developer working across frontend and backend, and I enjoy building infrastructure and data-driven applications that support real research.

🔭 &nbsp;I'm currently working on **I'm building ML pipelines and a React/Python annotation platform for pelvic floor MRI segmentation, using nnU-Net as part of my thesis research at USZ Zürich.**
