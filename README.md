## Projects

### [NodeRegrets](https://noderegrets.dev)

Dependency health checks for Node.js projects: what's outdated, what's vulnerable and
what changed since your version.

- Classifies every dependency update as major, minor or patch, with the release notes in between
- Matches [OSV.dev](https://osv.dev) advisories against the exact installed version and shows the fixing release
- Checks transitive dependencies, `engines` and peer-dependency compatibility, and flags unmaintained packages
- GitHub dashboard for monitoring repositories, plus a CLI: `npx noderegrets`

**Website:** [noderegrets.dev](https://noderegrets.dev)
